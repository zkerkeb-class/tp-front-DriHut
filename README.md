No real added features but overall added custom css to most of the components (sliders, inputs, file inputs, card using clip-shape oe corner-shape)
- Using swr for fetching because its easier and has infinite scroll (fun fact I made a swr like implmentation for angular at work and its been making wonders)
- Using material UI for some components because gain of time

The overall TP relies a lot on fetching extra data to populate the database with more rich data (and more structured too) and having a clean look to it. 
The infinite scroll uses a next cursor which is know to be faster than offesting (at least in sql databases from what I know).
The design has been made by Luciana so I won't take any pride in it but the implemtation was all mine and copilot autocompletion at most.

So in short its not feature rich just design rich 😊.
